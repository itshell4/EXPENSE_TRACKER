# Expense Tracker

A full-stack expense tracking application with user authentication, budget management, spending analytics, and CSV export.

## Tech Stack

- **Frontend**: React 18, Tailwind CSS, Recharts, React Router, Axios
- **Backend**: Node.js, Express, SQLite3
- **Authentication**: JWT (JSON Web Tokens)
- **Charts**: Recharts

## Features

- 🔐 User authentication (register/login)
- 💰 Add, edit, delete expenses with categories and dates
- 📊 Dashboard with spending trends (weekly/monthly charts)
- 📈 Category breakdown with pie charts
- 🎯 Monthly budget setting with overspend alerts
- 📥 Export expenses as CSV
- 📱 Responsive design with Tailwind CSS
